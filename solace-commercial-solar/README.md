# Solace Commercial Solar

A plain HTML, CSS and JavaScript rebuild of the supplied Solace commercial solar landing page.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript (interaction work is intentionally left for the learning phase)

## Project structure
- `index.html`: semantic page structure and content
- `css/style.css`: design system, layout and responsive styles
- `js/script.js`: reserved for JavaScript interactions we will build together
- `assets/`: image assets extracted from the supplied website archive

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Important content notes
The original archive referenced JavaScript bundles and platform scripts that were not included as source files. This rebuild does not depend on those bundles. Contact details and company statistics inherited from the supplied page should be verified before publishing. The estimate form is a front-end demonstration until a real calculation model and secure backend are connected.
